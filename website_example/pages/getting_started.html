About the algorithm (yescryptr32)

LuckyPepe mines with yescrypt (N=4096, r=32, personalization "WaviBanana"): a memory-hard CPU algorithm that needs about 16 MB per thread, over the 80-byte block header. The pool speaks the standard Bitcoin Stratum protocol. Block time is 60 seconds. The block reward is not a fixed, halving amount: it is a pseudo-random value inside a range that steps down every 262,800 blocks (currently 1,000,000-3,000,000 LPEPE per block); on top, 7% of every block's reward goes automatically to the chain's dev fund (a consensus rule enforced by every node, not a pool fee) - the rest is shared among miners.

  • poolpayminer support for yescryptr32 is being added; check the miner's GitHub page for the current status. Any Stratum miner implementing this exact yescrypt variant works.
  • yescrypt is a CPU algorithm: every thread needs roughly 16 MB of memory; any modern CPU works.

Software

  • poolpayminer (Windows x64 and Linux x86-64): source code and downloads once yescryptr32 support is published. A modified XMRig with TLS support. Fee 1% (1 minute in about 100), shown at start-up; details on the download page.
  • Wallet (to get your address): LuckyPepe Core from the project (releases).

Rewards and payments

  • Reward scheme: proportional with time weighting (older shares of a round weigh less).
  • Block rewards become spendable after 100 blocks (about 100 minutes); the pool credits your balance after that.
  • Payments are ordinary LPEPE transactions to your address. Everyone who is due is paid in one transaction per round, the network fee is shared by the paid miners.
  • Modes: prop:ADDRESS (shared reward, default) or solo:ADDRESS (the block finder takes the reward).

Об алгоритме (yescryptr32)

LuckyPepe майнится yescrypt (N=4096, r=32, персонализация "WaviBanana"): процессорный алгоритм, требующий около 16 МБ памяти на поток, над 80-байтным заголовком блока. Пул работает по стандартному протоколу Bitcoin Stratum. Время блока 60 секунд. Награда за блок не фиксирована и не делится пополам по расписанию: это псевдослучайная величина из диапазона, который снижается каждые 262 800 блоков (сейчас 1 000 000-3 000 000 LPEPE за блок); сверх того, 7% награды каждого блока автоматически уходит в фонд разработки сети (правило консенсуса, а не комиссия пула) — остальное делится между майнерами.

  • Поддержка yescryptr32 в poolpayminer готовится; следите за страницей майнера на GitHub. Подойдёт любой Stratum-майнер с этим вариантом yescrypt.
  • yescrypt — процессорный алгоритм: каждому потоку нужно около 16 МБ памяти; хватит любого современного процессора.

Программы

  • poolpayminer (Windows x64 и Linux x86-64): исходный код и загрузки — после публикации поддержки yescryptr32. Изменённый XMRig с поддержкой TLS. Комиссия 1% (1 минута из примерно 100), показывается при запуске; подробности на странице загрузок.
  • Кошелёк (чтобы получить адрес): LuckyPepe Core от проекта (релизы).

Награды и выплаты

  • Схема наград: пропорциональная с учётом времени (старые шары раунда весят меньше).
  • Награда за блок становится доступной через 100 блоков (около 100 минут); после этого пул зачисляет её на ваш баланс.
  • Выплаты это обычные транзакции LPEPE на ваш адрес. Все, кому пора платить, получают деньги одной транзакцией за раунд, комиссию сети делят между собой получатели.
  • Режимы: prop:АДРЕС (общая награда, по умолчанию) или solo:АДРЕС (награду забирает нашедший блок).
